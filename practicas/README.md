# Prácticas EBAC — Carni-mvp

Todas las prácticas del curso EBAC viven aquí. **Esta carpeta NO existe en `main`.**

> Ver `docs/BRANCH_WORKFLOW.md` en la rama `main` para las reglas de separación entre ramas.

## Estructura

```
practicas/
├── node/
│   └── practica-01/    # Node.js + Open-Meteo API
└── react/
    ├── practica-01/    # React — class components, state, componentDidMount
    └── practica-02/    # React + TypeScript — tipos, interfaces, props tipadas
```

## Reglas

- Cada práctica es **autónoma** — no importa de `src/app/` ni de la app principal.
- Los componentes usan datos del dominio Carni-mvp (products, orders, customers), no placeholders genéricos.
- Para correr una práctica individual, ver el `README.md` dentro de su carpeta.
