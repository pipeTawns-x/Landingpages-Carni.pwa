# Emil Kowalski skills (copied for Claude Design)

Source: https://github.com/emilkowalski/skills (MIT, see LICENSE). Copied unmodified on 2026-09-23 so the Claude Design project, which reads this folder from the `pruebas` branch, can follow the same animation and polish rules as the coding agents.

| Folder | Use it for |
| --- | --- |
| emil-design-eng | Overall polish: the small details that make an interface feel right |
| animate | Building one animation: purpose, property, curve, duration, interruption, exit |
| review-animations | Strict review of existing motion (STANDARDS.md has the rules) |
| find-animation-opportunities | Where motion helps and where it must not be added |
| apple-design | Apple-style fluid motion, springs, materials, typography |
| mobile-native | Making the 390 px layouts feel like an installed app |
| animation-vocabulary | Exact names for motion effects |
