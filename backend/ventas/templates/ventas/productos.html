{% load vite %} {% comment %} The store's real products.html, painted by Django (ventas:catalogo at /productos/, and the sheet of one product at /productos//). Same design, same sections: the header, the breadcrumb, the category rail with the grid of cards, the sheet where an order is configured, the cart drawer, the footer and the virtual assistant. One template, two modes, as the page had two routes: without `product` in the context it is the catalogue; with it, the sheet of that product. What differs from the static file is on purpose: - The catalogue was a React island that read Supabase from the browser; here Django paints the cards from the real catalogue, so the page is complete before any script runs, and the cart is the one of the session (the server's), not a second copy in localStorage. - The CSP of the site only admits 'self': no inline style, no inline script, no CDN. The styles and the scripts come from the Vite build ({% vite_asset %}), which writes Bootstrap before the site's own CSS. The weather widget (Open-Meteo) and Google Fonts do not fit the CSP. The header, the menu, the search, the footer and the assistant are partials in `parciales/` that the other pages can share. {% endcomment %} {% if product %}{{ product.name }} · {{ negocio.nombre }} {% else %}Productos · {{ negocio.nombre }} {% endif %} {% vite_asset "src/entry/products.tsx" %} Ir al contenido
