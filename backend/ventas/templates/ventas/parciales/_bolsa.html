{% comment %} The cart drawer ("Tu pedido"): a native modal , so the browser makes the page inert, keeps the focus inside, closes it with Escape and gives the focus back to the button that opened it. The header's cart button is a link to the cart page; the island opens this dialog instead, so without script the customer simply lands on the cart page. It lists the lines of the session (`bolsa`, from ventas.context_processors.tienda) without prices: the store quotes them on the cart page. Each line is removed with a plain POST that carries the CSRF token and comes back to the page the customer was on (`next`, with #bolsa so the drawer is still open). {% endcomment %}
